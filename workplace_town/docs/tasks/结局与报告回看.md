# 结局与报告回看

## 目标

修掉真机上「第 6 月没转正就结束了」后面那串断掉的体验，让一年走完（含第 7 月提前收口）之后有明确出口、报告能留下来回看：

1. 报告关闭后回到标题主页面；
2. 标题主页面能再次打开这一局的报告，全程离线、不依赖 `127.0.0.1:8077` 后端；
3. 第 12 月正常结束与第 7 月未转正 / 违纪解除两条结局共用同一个出口；
4. 真机触屏点得到、无报告时不出现死按钮。

## 关键决策

- **设计口径**：M6 只判一次；未转正 / 违纪解除在第 7 月交接 + `M07_CLOSURE` 短收束后收口，不开放 M8–M12，
  完整年度报告只对走完十二个月的人开放。用户看到的「结束了」是有意为之，**不改判定**；要修的是收口之后没有出口。
- **不引入 `yearDone` 续玩落点**：已结束的一局不接回小镇，回标题页看报告即可。保持 `_try_resume_saved_month()` 原样，
  避免为回看报告改动主流程续玩逻辑（也避开该线仍存在的 `--v12m-resume` 门槛，那是 §15.23 另一轮的事）。
- **报告文件独立落盘** `user://workplace_town_report.json`，不塞进 `workplace_town_month12.json`：不动续玩 payload 形状。
  路径常量放 `ReportPanel`，两个调用方引用同一处。
- **回看走 `open_with()`**：标题页不再调 `ReportPanel.open()`（那条走 `ApiClient.fetch_report()` 后端，真机必死）。
  `open()` 保留给旧 48 个月，不动。
- **`closed` 只在 `WorkplaceTown` 侧连一次**：标题页侧关报告就是留在标题页，不切场景。
- **新按钮不用 `_cover_button`**：该函数的几何 tween + `await tween.finished` 在触屏抬手补发 `mouse_exited` 时会死锁
  （开发册 §15.24）。用普通 `Button` + `_intro_button` 手绘底板，触屏可靠、风格一致。
- **不重新导出 Web 包 / 打 HAP**：等本轮验收与用户确认后统一打包。不 `git commit` / `push`。
