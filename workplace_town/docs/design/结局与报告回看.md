# 结局与报告回看

> 2026-11-11 建立。改动落点 `E:/03_Projects/bear/workplace_town_main_latest`。
> 本文件只写「一年结束（含第 7 月提前收口）之后怎么出去、报告怎么留下来回看」。
> 报告页**内部**的排版与滚动交互归 `阅读负担与交互.md`（尤其 §10 报告页滚动），本文不复制、不改动那份契约。

## 1. 现状的三个断点

| 断点 | 位置 | 后果 |
|---|---|---|
| 报告是一次性的 | `WorkplaceTown._open_month12_report()` 只 `build()` → `open_with()`，没有落盘 | 关掉后再也调不出来 |
| 报告没有出口 | `ReportPanel.closed` 全仓无消费者；`close()` 只 `visible=false` | 关掉后停在 `_month12_phase="done"` 的小镇，回不了标题页 |
| 标题页没有入口 | `StartupFlow._title_screen()` 只有 StartGame / Settings / ExitGame；`_open_report()` 无调用点，且调 `ReportPanel.open()` → `ApiClient.fetch_report()` → `127.0.0.1:8077` | 真机没有后端，接上按钮也会永远「正在生成…」 |

第 6 月未转正 / 违纪解除的路径在本线**已经有** `_end_year_early()` → `_open_month12_report()`（`WorkplaceTown.gd:6253`），
报告装配器也按 `probation_ended` 给出「截至第 7 月的报告」标题与对应 headline。所以这三条线共用同一个出口即可，不需要两套结局页。

## 2. 口径约束（三册）

- 算法册 §5.5、开发册 §15.7：M6 只判一次；未转正 / 违纪解除在**第 7 月交接后**收口，不开放 M8–M12，
  完整年度报告只对走完十二个月的人开放。第 7 月那份是「截至第 7 月的报告」，不得改称年度报告。
- 本轮**不改**判定门槛、不改剧情、不新增旗标、不新增玩家可见事实，只补工程缺口。
- 「不预告主线」：标题页按钮只写「我的报告」，不出现任何月份或剧情标题。
- 已结束的一局**不接回小镇**：结局之后重开游戏应当回到标题页看报告，而不是把 `done` 状态续玩回第 7/12 月。
  因此本轮不动 `_try_resume_saved_month()`，也不引入 `yearDone` 续玩落点（详见 §7 决策）。

## 3. 数据结构

### 3.1 报告存档文件 `user://workplace_town_report.json`

唯一来源常量：`ReportPanel.REPORT_SAVE_PATH`。`WorkplaceTown` 与 `StartupFlow` 都引用它，不各写字面量。

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | int | 固定 `1`，读侧遇到其它值当无报告 |
| `reason` | String | `year_end`（走满十二个月）/ `probation_ended`（第 7 月收口） |
| `month` | int | 生成时的 `_month12_month`（12 或 7），只用于排查，不驱动分支 |
| `savedAt` | String | `Time.get_datetime_string_from_system()`，只用于排查 |
| `data` | Dictionary | `Month12Report.build(town)` 的**完整返回值**，原样序列化 |

`Month12Report.build()` 的返回值只含 Dictionary / Array / String / 数字 / bool（已核：装配器内无 `Color`、`Vector2`、
`Object`、`Callable`），可直接 `JSON.stringify` / `JSON.parse_string`。落盘失败只 `push_warning`，不阻断报告展示。

### 3.2 内存与运行时状态

| 状态 | 位置 | 说明 |
|---|---|---|
| `_report_panel` | `WorkplaceTown` / `StartupFlow` | 各自按需实例化 `ReportPanel`，互不复用 |
| `closed` 信号 | `ReportPanel` | 已有；本轮只在 `WorkplaceTown` 侧连接一次，标题页侧不连 |

## 4. 接口定义

| 接口 | 签名 / 归属 | 行为 |
|---|---|---|
| `ReportPanel.REPORT_SAVE_PATH` | `const String` | 报告存档路径唯一来源 |
| `ReportPanel.load_saved_report()` | `static func -> Dictionary` | 读文件；文件不存在 / 内容为空 / JSON 不是 Dictionary / `version != 1` / `data` 不是 Dictionary 时返回 `{}`。只读，不写、不发请求 |
| `ReportPanel.save_report(data, reason, month)` | `static func -> void` | 组装 §3.1 的外层结构并写盘；`data` 为 `build()` 返回值。写失败 `push_warning` |
| `ReportPanel.open_with(data)` | 已有 | 用本地装配结果渲染，不请求后端 |
| `ReportPanel.open()` | 已有 | 保留给旧 48 个月后端报告；标题页**不再调用** |
| `ReportPanel.close()` | 已有 | 关详情浮层、隐藏、发 `closed` |
| `WorkplaceTown._open_month12_report(reason := "year_end")` | 改签名 | `build()` → `save_report()` → `open_with()`；首次建面板时 `closed.connect(_on_month12_report_closed)` |
| `WorkplaceTown._on_month12_report_closed()` | 新增 | `get_tree().change_scene_to_file("res://Startup.tscn")` |
| `WorkplaceTown._finish_month12()` | 改 | 传 `year_end` |
| `WorkplaceTown._end_year_early()` | 改 | 传 `probation_ended` |
| `StartupFlow._open_report()` | 改 | `load_saved_report()` → 有则 `open_with(report["data"])`；无则不打开 |
| `StartupFlow._title_screen()` | 改 | 增加 `MyReport` 按钮，按 `load_saved_report()` 是否为空决定可用状态 |

**连接约束**：`closed` 只在 `WorkplaceTown` 侧连一次（用 `is_connected` 判重，避免重复建面板时叠连）。
`StartupFlow` 侧关闭报告只是回到标题页本身，不切场景。

## 5. 流程

```
第 12 月结束 ──► _finish_month12()        ─┐
第 7 月收口  ──► _end_year_early()        ─┼─► _open_month12_report(reason)
   (未转正 / 违纪解除；M8–M12 不开放)      ─┘        │
                                                    ├─ build() 装配
                                                    ├─ save_report() 落 user://
                                                    └─ open_with() 展示
                                                              │
                                            点「关闭 ×」/ ui_cancel
                                                              ▼
                                            closed → change_scene_to_file(Startup.tscn)
                                                              ▼
                                        标题页「我的报告」← load_saved_report()
                                                              ▼
                                                    open_with(同一份 data)
```

两种结局只有 `reason` 与报告内 `pageTitle` / `headline` 不同，出口与回看路径完全一致。

## 6. 真机约束

- **离线**：回看链路全程本地文件 + `open_with()`，不出现 `ApiClient` 调用；鸿蒙 Web 壳没有 8077 后端也不受影响。
- **落盘**：`user://` 在 ArkWeb 落到 IndexedDB，依赖外壳 `Index.ets` 的 `.databaseAccess(true)`（开发册 §15.23）。
  核查发现 `workplace_town_main_latest` 原本只有 `.domStorageAccess(true)` / `.fileAccess(true)`，**缺这一行**；
  本轮已在 `entry/src/main/ets/pages/Index.ets` 的 Web 组件补上。缺了它，报告杀进程重开就丢，
  标题页回看只在同一会话内成立——所以这行是本功能能不能成立的前提，不算额外优化。
- **触屏**：`MyReport` 用普通 `Button`（`_intro_button` 的手绘底板），不复用 `_cover_button` 的
  `position/scale` tween + `await tween.finished`（该组合在触屏抬手补发 `mouse_exited` 时会死锁，见开发册 §15.24）。
  按钮点击区不小于 349×71。
- **无报告时**：按钮 `disabled=true`、文字「暂无报告」，不出现点了没反应的死按钮。

## 7. 关键决策

1. **不引入 `yearDone` 续玩落点**：已结束的一局不该接回小镇；标题页回看已经满足需求。
   保持 `_try_resume_saved_month()` 原样，避免为「回看报告」改动主流程续玩逻辑。
2. **报告文件独立存档**，不塞进 `workplace_town_month12.json`：避免改动续玩 payload 的形状，
   也避免「从头开始」清档时误删或漏删。代价是两份文件，由 §3.1 的常量约束。
3. **不改 `ReportPanel.open()`**：旧 48 个月报告仍走后端，保持只读边界。
4. **不新增结局页 / 新按钮文案**：第 7 月已有 `M07_CLOSURE` 短收束 + 阶段性报告，收口由「关报告 → 回标题」完成。
