# 小熊镇自习室 · 设计 V1

> 定位：面向备考大学生的轻量单机自习陪伴网页。一个固定 NPC 熊搭子坐在桌前自己备考，你写下目标坐下，它安静陪着、偶尔走神，你带它学。
> 本版只定设计，不写实现。目标是把场景、交互、动作、美术需求一次说清，之后照单落地。

---

## 0. 边界：这个自习室做多大

**只做一个核心循环，三个场景，一个 NPC，纯前端。**

| 做 | 不做 |
|---|---|
| 单人 + 固定一只熊搭子 | 联机 / 好友 / 房间 / 排行榜 |
| 3 个场景（入场 / 自习 / 结算） | 大地图、多楼层、自由走动 |
| 番茄钟 + 目标牌 + 熊的状态记忆 | 完整日程、成就系统、商城 |
| 2D 桌面立绘 + 分层动作 | 3D / 高斯泼溅 / 自由视角 |
| localStorage 存本地 | 后端、账号、大模型 |

一句话：**一屏一桌一只熊，把"它在学习、你也坐下了、它记得你"这三件事做透**，别的都不碰。

## 1. 场景设计（3 个，不多做）

### 场景 A · 入场（约 10 秒）
- 平视的书桌特写，熊已经在桌后坐着看书（第一眼就看到"它在学"）。
- 屏幕中央一张**座位牌**样式输入框：写一句今天的目标（"刷完 2 套行测"）。
- 一个"陪伴强度"选择：安静 / 正常 / 主动（默认正常）。
- 按钮"坐下"→ 进入场景 B。
- 熊此时台词："我占位子啦，你写下今天要干嘛。"

### 场景 B · 自习主场景（核心，90% 时间都在这）
- 画面：桌面特写。熊在上半部（头 + 上半身 + 手放在桌面），下半部是你的桌面（目标牌小卡、计时器、笔、杯子）。
- 俯视图书馆图只做**虚化背景**，不参与叙事，只是氛围。
- 常驻元素：倒计时（大）、你的目标小牌（可点开改）、陪伴强度图标、暂停/结束按钮。
- 熊的状态气泡在头顶，偶尔冒一句。
- 关键：**熊一直在做事**（看书、写字、喝水、走神），不是静态贴图。动作见第 3 节。

### 场景 C · 结算（约 15 秒）
- 结束计时后弹出：今天专注 X 分钟，连续第 N 天，座位为你留了 N 天。
- 熊的反应呼应目标：你写下过"刷完 2 套行测"→ 它抬头问"那两套刷完了吗？我也刚做完一套"（**问它自己，不评价你**）。
- 按钮"明天见"→ 回场景 A；"看看记录"→ 一个极简统计页（累计时长、打卡天数、柱状图）。

## 2. 交互设计（用户能做什么）

| 交互 | 在哪个场景 | 用户动作 | 反馈 |
|---|---|---|---|
| 写目标 | A | 输入一句话 | 写在座位牌上，带进场 |
| 选陪伴强度 | A | 三档按钮 | 决定熊说话频率 |
| 坐下 | A | 点按钮 | 计时开始，进 B |
| 开始 / 暂停 / 结束 | B | 按钮 + 空格键 | 计时状态 + 熊换动作 |
| 改目标 | B | 点目标小牌 | 弹回输入框，改完继续 |
| 时段切换 | B | 白天/傍晚/深夜 | 光影变化（纯 CSS 滤镜） |
| 戳一下熊 | B | 点熊 | 它抬头看你一眼，说一句，继续低头 |
| 切强度 | B | 小图标 | 立即改变话量 |
| 明天见 | C | 按钮 | 数据存本地，回 A |

**唯一新增交互是"戳一下熊"**——这是让用户主动和 NPC 发生关系的入口，比被动看它动更有"它在陪我"的感觉。点击不改变它的状态，只触发一次反应。

## 3. NPC 动作设计（回答"半身特写就没 NPC 什么事了"）

### 3.1 先把逻辑说清
镜头收窄不是让 NPC 没事干，是让它**动作可见**。全身小人时看不清它在干嘛；收窄到桌前半身，手在桌面上、脸在眼前，它做的每件事你都看得见——这才是"它是活的"的前提。
**真正让它变成摆设的，不是镜头大小，是只有换表情没有动作。** 所以这一版的核心是给熊一套动作系统。

### 3.2 动作分两层

**第一层：自主动作（它有自己的事，你不参与也会发生）**

| 动作 | 表现 | 时长 | 怎么实现 |
|---|---|---|---|
| 看书 | 头微低，手扶书 | 默认态 | 身体底图 + 低头头图 |
| 翻页 | 手抬一下、翻动 | 每 40–60 秒 | 换手部姿势图 |
| 写字 | 头低，手小幅移动 | 每段中穿插 | 换手图 + CSS 微动 |
| 端杯喝水 | 手举杯到嘴边，头微抬 | 每 3–5 分钟 | 换手图 + 头图 |
| 走神看窗外 | 头转向侧面，手停住 | 偶尔 | 换侧头图 |
| 打哈欠 / 困 | 头后仰、眼睛眯 | 长时间专注后 | 换头图 + 小图标 Zzz |
| 趴桌 | 头下压到桌面，手叠着 | 摸鱼态 | 换头图 + 整图下移旋转 |

**第二层：对你的反应（你的行为改变它）**

| 触发 | 它的反应 | 用什么 |
|---|---|---|
| 你点"坐下"开始专注 | 抬头看你一眼，点头，低头继续 | 头图切换 + 气泡 |
| 你暂停 | 抬头，疑惑/无奈脸 | 头图切换 |
| 你结束并达标 | 抬头，开心脸，挥手 | 头图 + 手图 |
| 你戳它 | 抬头看你，说一句，回去看书 | 头图 + 气泡 |
| 你连续几天来 | 它话变多、更放松（熟悉度 3 阶段） | 台词池按熟悉度切换 |
| 你几天没来 | 回来时它说"我以为你不来了"，趴着的精神变好 | 台词 + 状态值 |

### 3.3 关键实现思路：分层立绘（这是美术需求的核心）

现在的 5 张立绘是**整张站姿图**，只能整张换。要做上面这套动作，必须把熊拆成可拼装的部件：

```
一层  身体底图（坐姿，胸口以上，双手能放到桌面）—— 1 张
二层  头部/表情（复用现有 5 表情，裁出头部）—— 5 张
      额外补：低头、侧头、后仰/困、趴下 —— 约 4 张
三层  手部姿势（放在桌面上）—— 约 4 张
      扶书 / 写字 / 端杯 / 翻页
四层  眼睛层（眨眼）—— 可用 CSS 色块盖，或 1 张闭眼图
```

**这样画一次能拼出十几种动作**：换头图 + 换手图 + 整图位移，就是一套动作系统。这是最省美术的做法，也是让 NPC 从"贴图"变"角色"的关键。

## 4. 美术素材清单

### 现成能用的（不用改）
| 素材 | 路径 | 用途 |
|---|---|---|
| 陈工 5 表情立绘 | `workplace_town_main_latest/assets/角色立绘/陈工/` | 裁出头部，做表情层 |
| 树影图书馆 / D_人事部_独自学习 | `assets/场景内部图/`、`assets/活动场景/` | 虚化背景，氛围 |
| UI 底板、图标 | `assets/ui/`、`上架素材/图标方案/` | 目标牌、计时器面板 |

### 需要补的（老师已说素材可以改）
| 要画的图 | 数量 | 规格 | 优先级 |
|---|---|---|---|
| 坐姿身体底图 | 1 | 1024px 透明底，胸口以上，双手可放桌面 | **必须** |
| 头：低头 / 侧头 / 后仰困 / 趴下 | 4 | 与现有表情同风格同尺寸，能对上身体 | **必须** |
| 手：扶书 / 写字 / 端杯 / 翻页 | 4 | 桌面视角，能叠在桌面上 | **必须** |
| 桌面小物：摊开的书、杯子、笔、台灯 | 4 | 可画，也可用 CSS 画 | 可选 |
| 闭眼图 | 1 | 或用 CSS 色块代替 | 可选 |

**最小方案**：只画"身体底图 1 + 低头 1 + 趴下 1 + 手 2（扶书、写字）"，共 5 张，就能撑起"看书 → 写字 → 走神 → 趴桌"的循环。其余用现有 5 表情 + CSS 位移凑。
**完整方案**：上表全部画完，约 13 张，动作自然度明显上一个台阶。

诚实说：**这版比之前"换图 + CSS"多了 5–13 张图的美术量**，这是"NPC 有事干"必须付的代价。老师允许改素材，这笔投入是值得的——它就是"摆设"和"角色"的分界线。

## 5. 数据与状态（简述）

localStorage 存一个 JSON：

```
{
  目标文本, 陪伴强度,
  熊的状态值：{精力, 专注, 心情, 紧张度},  // 跨天累积，不重置
  熟悉度：1-3,
  记录：[{日期, 时长}],
  座位保留天数, 请假券剩余
}
```

规则：你专注 → 它专注值涨；你离开 → 它松一点；考试临近 → 它紧张度涨（有上限，必须有收尾）。台词按状态从对应组里抽，5–8 句一轮换。

## 6. 待确认（定这些才能开工）

1. **熊固定用陈工，还是换一只更"学生气"的？** 陈工是眼镜西装，当"督导"合适，当"一起备考的搭子"有点老气。备选：小林（绿开衫元气）、小赵（卷王）。
2. **美术谁画？** 你手绘 / 找美术生 / 还是再从现有图里裁切凑合？这决定第 4 节是"必须画"还是"尽量画"。
3. **"戳一下熊"要不要保留？** 保留则多一句交互和几张反应图，但它是"NPC 有用"最直接的证据。
