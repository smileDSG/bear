> 本版为**定稿**。三个此前悬而未决的问题——几维、用哪只熊、美术怎么来——已全部拍板，不再列为待确认。
> 之后照这份落地，不再改方向。

## 0. 三项拍板

| 问题 | 决定 | 理由（一句话） |
|---|---|---|
| 几维 | **2D**（分层立绘 + CSS 动画） | "像不像自习"取决于有没有一张对的画面和动作，跟维度无关；2D 能复用现有立绘、成本最低 |

## 1. 维度决策：为什么是 2D（说透，免得再纠结）

**"感觉好不好"和"几维"是两件事。** 动漫全是 2D，感染力比大多数 3D 强——差别在动画，不在维度。我们之前那版之所以"不像自习"，是因为画面错了：

- 俯视的空桌（地图素材）+ 站立的熊立绘（角色素材）硬凑 → 视角打架
- 熊被桌子拦腰切断，站在那里，不是坐着
- 桌上东西离熊很远，没有"正在学"的证据

**这三个问题，换成 3D 一个都解决不了**——3D 也得先有一张"熊伏案"的模型。真正的解法只有一条：一张**平视的书桌 + 一只坐着的熊 + 手边的书**。

一旦补上这张对的画面，2D 反而全面占优：

- **复用素材**：现有 5 表情立绘、俯视图书馆、UI 底板全部能用，不浪费
- **快速落地**：图片 + CSS，纯前端，一天能跑通
- **轻量**：没有 3D 引擎、没有 GPU 渲染、没有高斯泼溅（那个要几十张不同角度的真实照片，输入根本不对）

所以结论不是"退而求其次用 2D"，是**"用 2D 是这道题最优解"**。3D 和联机是 FocusTown 的路，它的成功有 2 人全职团队和千万级冷启动撑着，跟我们"轻量、快速落地"是两条赛道。

---

## 2. 边界：这个自习室做多大

**只做一个核心循环，3 个场景，1 个 NPC，纯前端。**

| 做 | 不做 |
|---|---|
| 单人 + 固定一只熊搭子（小林） | 联机 / 好友 / 房间 / 排行榜 |
| 3 个场景（入场 / 自习 / 结算） | 大地图、多楼层、自由走动 |
| 番茄钟 + 目标牌 + 熊的状态记忆 | 完整日程、成就系统、商城 |
| 2D 分层立绘 + CSS 动画 | 3D / 高斯泼溅 / 自由视角 |
| localStorage 存本地 | 后端、账号、大模型 |

一句话：**一屏一桌一只熊，把"它在学习、你也坐下了、它记得你"三件事做透**，别的都不碰。

## 3. 场景设计（3 个，不多做）

### 场景 A · 入场（约 10 秒）
- 平视书桌特写，小林已经坐在桌后看书（第一眼就看到"它在学"）。
- 中央一张**座位牌**输入框：写一句今天的目标（"刷完 2 套行测"）。
- "陪伴强度"三选一：安静 / 正常 / 主动（默认正常）。
- 按钮"坐下"→ 场景 B。
- 小林台词："我占位子啦，你写下今天要干嘛。"

### 场景 B · 自习主场景（核心，90% 时间）
- 画面：桌面特写。小林在上半部（头 + 上半身 + 手放桌面），下半部是你的桌面（目标牌小卡、计时器、笔、杯子）。
- 俯视图书馆图只做**虚化背景**，氛围用，不参与叙事。
- 常驻元素：大倒计时、目标小牌（可点开改）、陪伴强度图标、暂停/结束按钮。
- 状态气泡在头顶，偶尔冒一句。
- 关键：**小林一直在做事**（看书、写字、喝水、走神），不是静态贴图。动作见第 5 节。

### 场景 C · 结算（约 15 秒）
- 结束计时后弹：今天专注 X 分钟，连续第 N 天，座位为你留了 N 天。
- 小林的反应呼应目标但不评价你：写下"刷完 2 套行测" → 它抬头问"那两套刷完了吗？我也刚做完一套"（问它自己）。
- 按钮"明天见"→ 回 A；"看看记录"→ 极简统计页（累计时长、打卡天数、柱状图）。

## 4. 交互设计（用户能做什么）

| 交互 | 场景 | 用户动作 | 反馈 |
|---|---|---|---|
| 写目标 | A | 输入一句话 | 写在座位牌上，带进场 |
| 选陪伴强度 | A | 三档按钮 | 决定小林说话频率 |
| 坐下 | A | 点按钮 | 计时开始，进 B |
| 开始 / 暂停 / 结束 | B | 按钮 + 空格键 | 计时状态 + 小林换动作 |
| 改目标 | B | 点目标小牌 | 弹回输入框，改完继续 |
| 时段切换 | B | 白天/傍晚/深夜 | 光影变化（纯 CSS 滤镜） |
| 戳一下熊 | B | 点小林 | 它抬头看你一眼，说一句，继续低头 |
| 切强度 | B | 小图标 | 立即改变话量 |
| 明天见 | C | 按钮 | 数据存本地，回 A |

**唯一新增交互是"戳一下熊"**——让用户主动和 NPC 发生关系的入口，保留。点击不改变它的状态，只触发一次反应。

## 5. NPC 动作设计（回答"半身特写就没 NPC 什么事了"）

### 5.1 逻辑
镜头收窄不是让 NPC 没事干，是让它**动作可见**。全身小人看不清在干嘛；收窄到桌前半身，手在桌面、脸在眼前，每个动作都看得见。
**真正让它变摆设的，不是镜头大小，是只有换表情没有动作。**

### 5.2 动作分两层

**第一层：自主动作（你不参与也会发生）**

| 动作 | 表现 | 频率 | 实现 |
|---|---|---|---|
| 看书 | 头微低，手扶书 | 默认态 | 身体底图 + 低头头图 |
| 翻页 | 手抬一下、翻动 | 每 40–60 秒 | 换手部图 |
| 写字 | 头低，手小幅移动 | 每段穿插 | 换手图 + CSS 微动 |
| 端杯喝水 | 手举杯到嘴边，头微抬 | 每 3–5 分钟 | 换手图 + 头图 |
| 走神看窗外 | 头转向侧面，手停住 | 偶尔 | 换侧头图 |
| 打哈欠 / 困 | 头后仰、眼睛眯 | 长时间后 | 换头图 + Zzz 图标 |
| 趴桌 | 头压到桌面，手叠着 | 摸鱼态 | 换头图 + 整图下移旋转 |

**第二层：对你的反应（你的行为改变它）**

| 触发 | 反应 | 用什么 |
|---|---|---|
| 你点"坐下" | 抬头看你一眼，点头，低头继续 | 头图 + 气泡 |
| 你暂停 | 抬头，疑惑/无奈脸 | 头图 |
| 你结束达标 | 抬头，开心脸，挥手 | 头图 + 手图 |
| 你戳它 | 抬头看你，说一句，回去看书 | 头图 + 气泡 |
| 你连续几天来 | 话变多、更放松（熟悉度 3 阶段） | 台词池按熟悉度切换 |
| 你几天没来 | 回来时说"我以为你不来了"，精神变好 | 台词 + 状态值 |

### 5.3 关键：分层立绘（美术需求核心）

现有 5 张立绘是**整张站姿图**，只能整张换。要做上面这套动作，必须把小林拆成可拼装部件：

```
一层  身体底图（坐姿，胸口以上，双手放桌面）—— 1 张
二层  头部/表情（小林现有 5 表情裁出头部）—— 5 张（复用）
      补：低头、侧头、后仰困、趴下 —— 4 张
三层  手部姿势（放桌面）—— 补 4 张：扶书 / 写字 / 端杯 / 翻页
四层  眼睛层（眨眼）—— CSS 色块盖，或 1 张闭眼图
背景  平视书桌（台灯、摊开的书、杯子、窗）—— 补 1 张
```

**画一次拼出十几种动作**：换头图 + 换手图 + 整图位移，就是一套动作系统。这是最省美术的做法。

## 7. 数据与状态（简述）

localStorage 存一个 JSON：

```
{
  目标文本, 陪伴强度,
  小林状态值：{精力, 专注, 心情, 紧张度},  // 跨天累积，不重置
  熟悉度：1-3,
  记录：[{日期, 时长}],
  座位保留天数, 请假券剩余
}
```

规则：你专注 → 它专注值涨；你离开 → 它松一点；考试临近 → 紧张度涨（有上限，必须有收尾）。台词按状态从对应组抽，5–8 句一轮换。
